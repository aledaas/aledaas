# Current Engineering Model

```text
Requirement
      │
      ▼
     Mina
      │
      ▼
 Crystal Discovery
      │
      ├───────────────┐
      │               │
Existing         New Crystal
 Crystal              │
      │               │
   New Face           │
      └───────┬───────┘
              ▼
      Mission Control
              │
              ▼
     Orfebre / Workers
              │
              ▼
           Runner
              │
              ▼
Continuous Crystallization
```

> This workflow represents the current implementation model and continues to evolve together with DIAMONT.
